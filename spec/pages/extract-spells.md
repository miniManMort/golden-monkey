---
Name: Extract Spell Profiles
Menu Option: Spells / Extract
Status: Implemented
---

The extract dialog provides:
- Sort order: Name or Level / Name.
- Output file name and location in OpenDocument Text (`.odt`) format.
- An Extract action that writes every spell profile in the selected order.
- Each spell is shown with its name as a heading, a table of Level, Range, Duration, and Save Allowed, followed by its effect.
