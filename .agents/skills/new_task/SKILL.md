---
name: new-task
description: Guide for adding a task to the workbook
---

Use the task-template.md file in .agents/skills/new_task to create a new task plan in work/plans/{task-id}.md. prompt the user for a short name and a longer more detailed desciption of the task. The short name will be used as the title of the task plan and the longer description will be used in the outline section of the task plan.

Add the new task to the summery in work/README.md. The task should be added to the list of tasks in the order that it was created. The task should be added to the list of tasks with a status of Proposed.
