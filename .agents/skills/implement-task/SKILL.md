name: implement-task
description: Guide for carrying out a specified task
---

First review the architecture specified in spec/README.md and the task details in work/plans/{task-id}.md.

On completion of the task, update the status in work/plans/{task-id}.md to reflect the current state of the task and put a log of the work carried out in work/logs/{task-id}.md. Update the workbook summary in work/README.md to reflect the current state of the task.
