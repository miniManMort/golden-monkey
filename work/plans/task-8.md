# Outline
This task adds the ability to extract monster profiles to an open document format file.

- Add menu option Extract to monster menu on home page
- On choosing Extract show dialog asking how the data is to be sorted (options are by Name or by Level/Name) and the location/name for the file to be created
- All moster details are then added to the new file in the order requested.
