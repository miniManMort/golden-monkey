# Outline
This task adds the specials field to the [create monster](app/create_monster_page.py), [modify_monster](app/modify_monster_page.py) and the monster details dialog in the [list monster](app/list_monsters_page.py) pages.

- the specials text is displayed in a multi line text field.
- saving on a create/modify saves the text to the database.
- When creating a monster, the text defaults to None.
