# Outline
This task implements the edit details button on the [list-spells](spec/pages/list-spells.md) page. 

- on each row of the table add an edit details button
- on clicking on the button display the modify-spell page.
- On clicking Save button save changes to the database.
- On clicking Delete button ask the user if they wish to delete this spell. If they answer yes delete the spell from the database.
