# Outline
This task implements the edit details button on the [list-monster](spec/pages/list-monsters.md) page. 

- on each row of the table add an edit details button
- on clicking on the button display the modify-monster page.
- On clicking Save button save changes to the database.
- On clicking Delete button ask the user if they wish to delete this monster. If they answer yes delete the monster from the database.
